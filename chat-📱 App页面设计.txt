## 页面文档

### 页面名称
**GalleryView — 画廊主界面（列表模式）**

---

### 页面职责
作为 App 的核心入口，展示用户相册中所有 RAW 相关照片，支持按来源过滤、按日期分组浏览、快速跳转编辑/对比。[1]

---

### UI 组件说明

| 区域 | 组件 | 说明 |
|------|------|------|
| 导航栏 | `NavigationTitle` (inline) | 固定不折叠，右侧 `⋯` 菜单含列表/网格切换 [1] |
| 顶部过滤 | `Segmented Control` | RAW+JPG 配对 / 仅 RAW-Only 两档切换 [1] |
| 列表 | `LazyVStack` + Section | 按日期分组，含 pinned Section Header [1] |
| 单元格 | `PhotoCardView` | 缩略图 + 相机型号 + 镜头参数 + 资源类型标记 |
| 底部指示 | `ProgressView` | 扫描未完成时显示"正在扫描更多照片…" [1] |
| 工具栏 | 相册选择 / 批量选择 / 网格切换 | 三个操作入口 |

---

### 交互流程

```
用户进入 App
      │
      ▼
权限检查 ──拒绝──▶ PermissionDeniedView
      │ 授权
      ▼
全屏 Loading Spinner（首次扫描）
      │ 首批50张就绪
      ▼
GalleryView 列表渐进显示
      │
  ┌───┴────────────────────────────┐
  │                                │
点击单元格                    点击"批量选择"
  │                                │
  ▼                                ▼
CompareView               多选模式 + 底部 ActionBar
（照片对比/查看页）
```

---

### 状态枚举

| 状态 | 表现 |
|------|------|
| 加载中（首次） | 全屏 `ProgressView` spinner [1] |
| 加载中（增量） | 列表底部 "正在扫描…" 小指示条 |
| 空状态 | `EmptyStateView`（无 RAW 照片提示）[1] |
| 正常 | 按日期分组列表 |
| 批量选择 | 单元格出现勾选框，底部弹出 ActionBar |

---

### 设计备注

- **性能**：使用 `LazyVStack` 代替 `List` 实现真正懒加载；缩略图用 `NSCache` 缓存，每个 cell 通过 `.task(id:)` 独立加载 [1]
- **扫描机制**：`AsyncStream` 每 50 张 yield 一次，后台 `Task.detached` 执行，UI 增量更新 [1]
- **本地化**：支持中英文，所有字符串走 `Localizable.xcstrings` [1]

## 页面文档

### 页面名称
**CompareView — 全屏照片查看 & 操作页**

---

### 页面职责
展示单张照片的全屏预览，支持 RAW/JPG 切换对比、缩放查看、元数据展示，并提供核心操作（保留/分割/HDR 导出/编辑/删除）[1]

---

### UI 组件说明

| 区域 | 组件 | 说明 |
|------|------|------|
| 导航栏 | `NavigationBar` | 左侧返回，右侧 RAW/JPG 切换按钮（仅配对时显示）[1] |
| 格式徽章 | 左上角 Badge | 绿色 = RAW，黄色 = JPG [1] |
| 主预览区 | `ZoomableScrollView` | UIScrollView-backed，支持双指缩放 + 平移 [1] |
| 滑动切换 | Swipe Gesture | 左右滑动切换照片（未缩放时生效）[1] |
| EXIF 栏 | 底部渐变遮罩层 | 相机型号、分辨率、文件大小、光圈、快门、ISO、焦距 [1] |
| 操作栏 | `ActionBarView` | 配对：保留JPG / 保留RAW / 分割▼；RAW-Only：自适应HDR / Ultra HDR [1] |
| 工具栏 | `toolbar` | 编辑按钮（跳转对应编辑器）+ 删除按钮（Trash）[1] |

### 状态枚举

| 状态 | 触发条件 | 表现 |
|------|----------|------|
| 正常预览 | 图片已加载 | 全屏照片 + EXIF 栏 + 动作栏 |
| iCloud 下载中 | 本地无缓存 | 居中 loading + 进度条，返回可用 [1] |
| 保存处理中 | 点击保留/分割/HDR | 处理遮罩，返回按钮隐藏 [1] |
| 操作完成 | 导出成功 | Toast 提示（可选 Undo）|

### 设计备注

- **黑色背景**：全屏黑底，沉浸式体验 [1]
- **动作栏逻辑**：配对模式下，无论当前预览 RAW 还是 JPG，动作栏始终显示 Keep JPG / Keep RAW / Split，不随切换改变 [1]
- **操作后行为**：保留/分割完成后停留当前页（非破坏性），仅删除会跳转 [1]
- **编辑器路由**：当前预览 RAW → `RAWEditorView`；当前预览 JPG → `JPGEditorView` [1]

## 页面文档

### 页面名称
**GalleryView — 网格模式 + 批量选择**

---

### 页面职责
以 3 列网格形式展示 RAW 照片，支持多选批量操作（保留/分割/HDR 导出），提供相册切换与进度反馈 [1]

---

### UI 组件说明

| 区域 | 组件 | 说明 |
|------|------|------|
| 导航栏 | 正常模式：标题 + 菜单；选择模式：取消 + 已选数量 | 模式切换时动画过渡 |
| 网格 | `LazyVGrid` 3列 + Section Header（pinned）| 按日期分组，与列表视图一致 [1] |
| 网格单元格 | `PhotoGridItemView` | 缩略图 + 左下角格式徽章（● RAW+JPG / ● RAW）|
| 选择状态 | 右上角圆圈 | 未选：空圆圈；已选：蓝色勾选圆圈 |
| 批量操作栏 | `BatchActionBarView` | 底部弹出，内容随 Segmented Control 切换 [1] |
| 批量进度 | `BatchProgressView` | 全屏遮罩 + 进度条 + 当前处理描述 [1] |
| 空状态 | `EmptyStateView` | 图标 + 标题 + 描述文字 [1] |
| 相册选择 | Sheet | 智能相册 + 用户相册，顺序与 Photos App 一致 [1] |

---

### 批量操作栏内容对比

| 过滤模式 | 操作按钮 |
|----------|----------|
| RAW+JPG 配对 | 保留 JPG / 保留 RAW / 分割 / HDR ▼ |
| RAW-Only | 自适应 HDR / Ultra HDR |

### 交互流程

```
网格模式正常浏览
      │
      ├── 点击单元格 → CompareView（同列表模式）
      │
      ├── 长按单元格 → 进入批量选择模式
      │
      └── 点击"批量选择"按钮 → 进入批量选择模式

批量选择模式
      │
      ├── 点击单元格 → 切换选中/取消选中状态
      │
      ├── 点击"取消" → 退出选择模式，清空已选
      │
      └── 点击操作按钮（保留JPG/RAW/分割/HDR）
                │
                ▼
          BatchProgressView 显示
                │
                ▼ 逐张处理
          进度更新（x/total）
                │
                ▼ 全部完成
          Toast 提示结果 → 退出选择模式

⋯ 菜单
      │
      ├── 切换列表/网格 → 布局动画切换
      └── （其他菜单项预留）

相册按钮
      │
      ▼
相册选择 Sheet → 选择相册
      │
      ▼
重新扫描该相册内的 RAW 照片
```

### 状态枚举

| 状态 | 触发条件 | 表现 |
|------|----------|------|
| 正常网格 | 默认 | 3列网格 + 日期分组 |
| 批量选择 | 长按/点击批量选择 | 圆圈出现，导航栏变化，底部操作栏弹出 |
| 批量处理中 | 点击操作按钮 | `BatchProgressView` 全屏遮罩 [1] |
| 空状态 | 无 RAW 照片 | `EmptyStateView` [1] |
| 加载中 | 初次扫描 | 全屏 spinner |
| 增量加载 | 扫描进行中 | 底部"正在扫描更多照片…"[1] |

### 设计备注

- **网格与列表共用数据源**：切换布局不重新扫描，仅改变渲染方式 [1]
- **Section Header pinned**：网格视图的日期 Header 与列表视图一样保持固定 [1]
- **批量 HDR 注意**：批量 HDR 导出使用默认 RAW 渲染参数，不应用每张照片的独立编辑参数 [1]
- **选择数量显示**：导航栏标题实时更新"已选择 N 项"
- **长按进入选择**：与系统 Photos App 交互习惯一致
